日期：2026/07/18

===============================================================================
 1. 硬體環境確認
===============================================================================

  Quixant 平台 COM Port 配置：
  
    COM1 ~ COM4 : 標準 RS-232（Quixant Communications Port）
    COM5        : SAS 專用 UART（9-bit 硬體，非標準 RS-232）
    COM6        : 標準 RS-232
    COM12       : USB 轉 RS-232（ATEN Prolific PL2303GC，外接）

  COM Port 對連測試結果：
  
    COM3 <-> COM4 : 雙向正常（外部 null modem 線）
    COM12 <-> COM6: 雙向正常（外部 null modem 線）
    COM5 <-> COM6 : 單向異常（COM5 是 SAS 專用硬體，標準 RS-232 不相容）
    COM1 <-> COM2 : 無內部對連
    其他組合      : 無內部對連

  關鍵發現：
    - COM5 的 SAS UART 會對收到的資料做硬體處理（1 byte 變 4 bytes，bit7 被修改）
    - COM5 送出的資料 COM6 收不到（單向不通）
    - 但 Quixant SDK 透過 COM5 做 SAS 通訊是正常的
    - IGT SAS Simulator (sastest.exe) 用 COM6 可以跟 COM5 的 EGM 正常通訊


===============================================================================
 2. 軟體架構
===============================================================================

  GSA SAS Host Simulator 由兩個程式組成：
  
    SASHostSim.exe : Windows GUI 控制介面
    gsat.exe       : DOS 引擎程式，實際執行 SAS 通訊

  GUI 與 Engine 之間使用 GEP (GUI-Engine Protocol) 透過 COM Port 通訊。
  Engine 透過另一個 COM Port 跟 EGM 做 SAS 通訊。

  gsat.exe 在 DOS 環境中的 COM Port 配置：
    DOS COM1 (0x3F8, IRQ4) = GEP（跟 GUI 通訊）
    DOS COM2 (0x2F8, IRQ3) = SAS（跟 EGM 通訊）


===============================================================================
 3. 最終架構
===============================================================================

  SASHostSim.exe (COM3) <--線--> COM4 (DOSBox serial1 = gsat GEP)
  gsat.exe SAS   (COM6) <--線--> COM5 (EGM 遊戲程式, Quixant SAS UART)

  ┌─────────────────┐              ┌────────────────────────────┐
  │  SASHostSim.exe │◄── COM3/4 ──►│  DOSBox-X (gsat.exe)       │
  │  (Windows GUI)  │   null modem │  GEP: serial1 = COM4       │
  └─────────────────┘              │  SAS: serial2 = COM6       │
                                   └──────────────┬─────────────┘
                                                  │ COM6 (null modem)
                                                  ▼
                                   ┌───────────────────────────┐
                                   │  EGM 遊戲程式              │
                                   │  (Quixant SDK, COM5)       │
                                   └───────────────────────────┘

 4. DOSBox-X 安裝
===============================================================================

  下載：https://github.com/joncampbell123/dosbox-x/releases
  版本：dosbox-x-mingw64-2026.07.02-portable.zip
  解壓位置：G:\GSA SAS Host Simulator v1.1\DOSBox\dosbox-x\

  配置檔：G:\GSA SAS Host Simulator v1.1\DOSBox\dosbox-x.conf

  重要設定：
    [cpu]
    core=auto
    cputype=pentium        ; gsat.exe 是 DJGPP 編譯的 386 保護模式程式
                           ; pentium 最接近原始運行環境，不需要更高
                           ; pentium_mmx 以上搭配 cycles=max 會導致卡住
    cycles=max             ; 最高速度，讓 polling cycle 跑夠快
                           ; 如不穩定退回 200000

    [serial]
    serial1=directserial realport:COM4    ; GEP -> GUI
    serial2=directserial realport:COM6    ; SAS -> EGM

  CPU 設定說明：
    cputype = 模擬哪種 CPU 的指令集和行為（不影響速度）
    cycles  = 每秒執行多少條指令（影響實際速度）
    
    gsat.exe 只需要 386 保護模式指令，設 pentium 即可。
    cycles=max 讓 DOSBox 盡可能跑最快，確保 5 秒內能完成 polling cycle。
    
    穩定的組合：cputype=pentium + cycles=32000
    備選組合：  cputype=pentium + cycles=max（較快但可能不穩定）

 5. 啟動與關閉
===============================================================================

  啟動：雙擊「啟動SAS測試環境.bat」
  
    自動執行：
      1. 關閉舊的 DOSBox 和 SASHostSim
      2. 啟動 DOSBox + gsat.exe（等 6 秒初始化）

      4. SASHostSim 中選 COM3，等綠燈亮起
      5. 啟動 EGM 遊戲程式（COM5）
      6. 勾選 Enable SAS Progressive Broadcast
      7. Start Polling Loop

  關閉：雙擊「關閉SAS測試環境.bat」

 6. SASHostSim 設定
===============================================================================

  Communication Port: COM3
  Polling Loop: Basic_1（或自訂 my_loop）
  Enable SAS Progressive Broadcast: 勾選

  Progressive 設定 (Configure -> Settings -> Progressives)：
    Broadcast address: 0
    Send multiple progressive updates in a single poll (86): 勾選
    Progressive group: 1
    Delay between progressive updates (ms): 1000
    Level 1: 勾選, Amount = 10000015
    Level 2: 勾選, Amount = 2000015
    Level 3: 勾選, Amount = 300000
    Level 4: 勾選, Amount = 40000
    Level 5: 勾選, Amount = 5000
    Level 6: 勾選, Amount = 600

  儲存設定：主畫面右下角按 Save（存到 Test Configuration Template）

 7. 疑難排解紀錄
===============================================================================

  問題：SASHostSim 顯示 NO CONNECTION
  原因：gsat.exe 未啟動，或 COM Port 設定錯誤
  解法：確認 DOSBox 先啟動，確認 SASHostSim 選 COM3

  問題：DOSBox 啟動後卡住不能操作
  原因：cycles 設太高，或 cputype 設太高階（pentium_mmx 以上 + cycles=max）
  解法：用 cputype=pentium + cycles=max，或降低 cycles=200000

  問題：cputype 設 pentium_mmx/pentium_iii 後卡住
  原因：高階 CPU 模擬邏輯較複雜，serial port 處理來不及
  解法：gsat.exe 只需 386 指令集，設 cputype=pentium 即可，不需更高

  問題：EGM 報 Link Down
  原因：gsat.exe 的 polling cycle 太慢，或 serial timing 不準確
  解法：調高 cycles（200000+），或精簡 Polling Loop

  問題：EGM 報 Progressive Timeout
  原因：LP 86 未定期送出，或 level 數量/group ID 不匹配
  解法：
    - 確認 Enable SAS Progressive Broadcast 有勾選
    - 確認 Progressive group = 1
    - 確認設定 6 個 level（跟 EGM 遊戲端一致）
    - 確認 Send multiple progressive updates (86) 有勾選
    - 調高 cycles 讓 polling cycle 跑更快

  問題：COM12 (USB-RS232) 做 SAS port 會讓 DOSBox 卡住
  原因：USB 轉接器在對面沒連接時不提供 CTS 信號，gsat.exe 等待 CTS block
  解法：不用 COM12 當 SAS port，改用 COM6

  問題：用 Bridge (TCP) 方式時 EGM 不回應
  原因：Bridge 的 mark/space parity wake-up bit 時機不夠精確
  解法：去掉 Bridge，直接用 COM6 directserial（實測可用）

 8. 曾嘗試但放棄的方案
===============================================================================

  方案 A：com0com 虛擬序列埠
    結果：不需要，Quixant 已有足夠的實體 COM Port

  方案 B：SAS Bridge (TCP 中繼 + mark/space parity)
    結果：可以通但不穩定（增加延遲導致 link down），
          且直接用 COM6 directserial 即可，不需要 Bridge

  方案 C：COM12 (USB) 當 SAS port
    結果：DOSBox 會卡住（CTS 等待），放棄

  方案 D：DOSBox serial2 = COM5（直接接 SAS UART）
    結果：COM5 是 SAS 專用硬體，directserial 不相容

===============================================================================
         GSA SAS Host Simulator v1.1 - 同機部署說明
===============================================================================

本文件說明如何在同一台 Windows 電腦上，讓 SASHostSim.exe (GUI) 和
gsat.exe (SAS Engine) 透過兩個實體 COM Port 對連通訊。


===============================================================================
 系統需求
===============================================================================

  - Windows 作業系統
  - 至少兩個實體 COM Port（本機有 COM1~COM6 Quixant Communications Port）
  - 一條 Null Modem 串列線（交叉線，連接兩個 COM Port）
  - DOSBox-X（用來在 Windows 上執行 DOS 引擎程式 gsat.exe）


===============================================================================
 架構說明
===============================================================================

  ┌─────────────────┐   Null Modem Cable   ┌─────────────────────────────┐
  │  SASHostSim.exe │◄──── COM1 ↔ COM2 ────►│  DOSBox-X 中的 gsat.exe     │
  │  (Windows GUI)  │                        │  (SAS Engine, DOS 程式)     │
  └─────────────────┘                        └──────────────┬──────────────┘
                                                            │
                                                       COM3 或其他 port
                                                            │
                                                            ▼
                                                   ┌───────────────┐
                                                   │   EGM 博弈機台  │
                                                   └───────────────┘

  註：如果只是測試 GUI 與 Engine 之間的連線，不需要接 EGM。


===============================================================================
 步驟一：硬體連接
===============================================================================

  1. 準備一條 Null Modem（交叉）串列線
     - DB9 母對母交叉線，或 DB9 公對公 + 交叉轉接頭
     - 交叉線的接法：Pin 2(TxD) ↔ Pin 3(RxD)，Pin 7(RTS) ↔ Pin 8(CTS)
     
  2. 將線的一端接到 COM1，另一端接到 COM2
     - 如果你用不同的 port，請修改下方的配置

  注意：如果兩個 COM Port 在主機板內部已有跳線對連（某些 Quixant 平台支援），
        則不需要外部線材。


===============================================================================
 步驟二：安裝 DOSBox-X
===============================================================================

  1. 到以下網址下載 DOSBox-X：
     https://github.com/joncampbell123/dosbox-x/releases

  2. 選擇最新版本中的 "dosbox-x-mingw-win64-XXXXXXXX.zip" 檔案下載

  3. 解壓縮到以下目錄：
     G:\GSA SAS Host Simulator v1.1\DOSBox\dosbox-x\

  4. 確認以下檔案存在：
     G:\GSA SAS Host Simulator v1.1\DOSBox\dosbox-x\dosbox-x.exe


===============================================================================
 步驟三：啟動 SAS Engine（先啟動）
===============================================================================

  1. 雙擊執行：
     G:\GSA SAS Host Simulator v1.1\DOSBox\start_engine.bat

  2. DOSBox-X 視窗會開啟，自動掛載 SAS Engine 目錄並執行 gsat.exe
  
  3. 如果看到 gsat.exe 的畫面正常顯示，表示引擎已啟動成功


===============================================================================
 步驟四：啟動 SASHostSim.exe（後啟動）
===============================================================================

  1. 雙擊執行：
     G:\GSA SAS Host Simulator v1.1\SASHostSim.exe

  2. 在主畫面的 COM Port 下拉選單中選擇 COM1
     （或你連接 null modem 線的那個 port）

  3. 狀態列應該會顯示連線成功（Connected）

  4. 選擇測試配置，開始操作


===============================================================================
 修改 COM Port 對應
===============================================================================

  預設設定：
    - GUI (SASHostSim.exe) 使用 COM1
    - Engine (gsat.exe/DOSBox) 使用 COM2

  如果你的 null modem 線接的是其他 port（例如 COM3 ↔ COM4），需要修改：

  1. 編輯 DOSBox\dosbox-x.conf 檔案
     找到 [serial] 區段，將：
       serial1=directserial realport:COM2
     改為：
       serial1=directserial realport:COM4

  2. 在 SASHostSim.exe 中選擇 COM3（線的另一端）


===============================================================================
 COM Port 通訊參數（供參考）
===============================================================================

  GUI 與 Engine 之間的通訊：
    Baud Rate:  19200
    Data Bits:  8
    Parity:     None
    Stop Bits:  1
    Flow Ctrl:  None

  這些參數由程式自動設定，通常不需要手動調整。


===============================================================================
 疑難排解
===============================================================================

  問題：狀態列沒有顯示 Connected
  ──────────────────────────────────
  1. 確認 Engine (gsat.exe) 已經先啟動
  2. 確認 null modem 線有正確連接兩個 port
  3. 確認 GUI 選的 COM Port 是線的其中一端
  4. 確認 dosbox-x.conf 中設定的是線的另一端
  5. 試著重新啟動兩個程式（先關 GUI，再關 DOSBox，再重新來過）

  問題：DOSBox 啟動後 gsat.exe 報錯或閃退
  ──────────────────────────────────────────
  1. 確認 SAS Engine 資料夾內有 cwsdpmi.exe 和 gsat.exe
  2. 試著在 dosbox-x.conf 中將 cycles=max 改為 cycles=5000
  3. Engine 偶爾會 crash，這是已知問題，重新啟動即可

  問題：找不到 COM Port
  ──────────────────────
  1. 開啟裝置管理員，確認「連接埠 (COM & LPT)」下有列出 port
  2. 確認沒有其他程式佔用該 COM Port

FILE: start_engine.bat  (1421 bytes, utf-8-sig)
@echo off
REM ============================================
REM  GSA SAS Engine Launcher
REM  Starts gsat.exe inside DOSBox-X
REM ============================================
REM
REM Prerequisites:
REM   1. Download DOSBox-X from: https://github.com/joncampbell123/dosbox-x/releases
REM      Choose: dosbox-x-mingw-win64-XXXXXXXX.zip
REM   2. Extract to: G:\GSA SAS Host Simulator v1.1\DOSBox\dosbox-x\
REM      So that dosbox-x.exe is at: G:\GSA SAS Host Simulator v1.1\DOSBox\dosbox-x\dosbox-x.exe
REM   3. Connect null modem cable between COM1 and COM2 (or edit dosbox-x.conf)
REM
REM Connection Layout:
REM   SASHostSim.exe (GUI) uses COM1
REM   DOSBox/gsat.exe (Engine) uses COM2
REM   COM1 <--null modem cable--> COM2
REM

set DOSBOX_DIR=%~dp0dosbox-x
set CONF_FILE=%~dp0dosbox-x.conf

if not exist "%DOSBOX_DIR%\dosbox-x.exe" (
    echo.
    echo ERROR: DOSBox-X not found!
    echo.
    echo Please download DOSBox-X and extract it to:
    echo   %DOSBOX_DIR%\
    echo.
    echo Download from: https://github.com/joncampbell123/dosbox-x/releases
    echo Choose the "dosbox-x-mingw-win64" zip file.
    echo.
    pause
    exit /b 1
)

echo Starting GSA SAS Engine in DOSBox-X...
echo.
echo Connection: GUI(COM1) ^<--null modem--^> Engine(COM2)
echo.
echo After DOSBox starts, gsat.exe will run automatically.
echo Then start SASHostSim.exe and select COM1.
echo.

"%DOSBOX_DIR%\dosbox-x.exe" -conf "%CONF_FILE%"

FILE: 啟動SAS測試環境.bat  (1577 bytes, utf-8-sig)
@echo off
REM ============================================
REM  GSA SAS Host Simulator - One-Click Launcher
REM ============================================
REM
REM Architecture (no Bridge):
REM   SASHostSim (COM3) <-wire-> COM4 (gsat GEP)
REM   gsat SAS (COM6) <-wire-> COM5 (EGM Game)
REM
REM Start Order: DOSBox(gsat) -> SASHostSim -> EGM Game
REM

echo ============================================
echo  GSA SAS Host Simulator - Launcher
echo ============================================
echo.

REM Step 0: Kill any existing instances
echo Closing existing instances...
taskkill /F /IM dosbox-x.exe >nul 2>&1
taskkill /F /IM SASHostSim.exe >nul 2>&1
taskkill /F /IM dotnet.exe >nul 2>&1
timeout /t 2 /nobreak >nul

REM Step 1: Start DOSBox (gsat.exe Engine)
echo.
echo [1/2] Starting SAS Engine (DOSBox + gsat.exe)...

REM Generate autoexec with correct absolute path
set SAS_ENGINE_PATH=%~dp0SAS Engine
(
echo mount c "%SAS_ENGINE_PATH%"
echo c:
echo gsat.exe
) > "%~dp0DOSBox\autoexec.bat"

start "" "%~dp0DOSBox\dosbox-x\dosbox-x.exe" -conf "%~dp0DOSBox\dosbox-x.conf" -c "mount c \"%SAS_ENGINE_PATH%\"" -c "c:" -c "gsat.exe"
echo       Waiting 6 seconds for Engine to initialize...
timeout /t 6 /nobreak >nul

REM Step 2: Start SASHostSim GUI
echo [2/2] Starting SAS Host Simulator GUI...
start "" "%~dp0SASHostSim.exe"
echo.

echo ============================================
echo  Both programs launched!
echo.
echo  - SASHostSim: select COM3, wait for green light
echo  - Then start your EGM game (COM5)
echo ============================================
echo.
pause
