參考資料
Long Poll | 說明 | 方向
4C | Set Secure Enhanced Validation ID | Host → EGM
4D | Send Enhanced Validation Information | Host → EGM（EGM 回報 ticket 資料）
58 | Receive Validation Number | EGM → Host
70 | Send Ticket Validation Data | Host → EGM（ticket redemption）
71 | Redeem Ticket | Host → EGM
7B | Extended Validation Status（控制 printer/handpay/restricted/redemption） | Host → EGM
7C | Set Extended Ticket Data（Location/Title/Address） | Host → EGM
7D | Set Ticket Data（Host ID/Expiration/Name/Address） | Host → EGM
A0 | Send Enabled Game Features | Host → EGM
Exception Code | 說明
3D | A cashout ticket has been printed
3E | A handpay receipt has been printed
3F | Validation ID not configured（每 15 秒重送）
67 | Ticket inserted（等待 host 驗證）
Validation Type Code | 說明
00 | Cashable ticket
01 | Restricted promotional ticket
02 | Non-restricted promotional ticket
10 | Cancelled credit handpay with receipt
20 | Jackpot win handpay with receipt
40 | Cancelled credit handpay without receipt
60 | Jackpot win handpay without receipt
7B Status Bit | 說明
Bit 0 | Printer as cashout device（1=可用）
Bit 1 | Printer as handpay receipt device（1=可用）
Bit 2 | Handpay validation & receipt configured（1=已啟用）
Bit 3 | Printing restricted tickets allowed（1=允許）
Bit 4 | Printing foreign restricted tickets allowed（1=允許）
Bit 5 | Ticket redemption allowed（1=允許）
Bit 6~14 | Reserved (= 0)
Bit 15 | Secure enhanced currently configured（1=已設定）
10.2.1 Secure Enhanced Validation Configuration
測試需求 | [1] 10.2.1
驗證項目 | Long Poll A0 — Send Enabled Game Features | Exception 3F — Validation ID not configured | Long Poll 4C — Set Secure Enhanced Validation ID
HostSim 設定 | Test Group: Enhanced Validation, Test Number: TEST_10.02.01
One Key Polls | F1 = A0-Send Enabled Features Game 0, address 1 | F2 = 4C-Set Validation ID seq 1, address 1 | F3 = 4C-Set Validation ID seq 99, address 1 | F4 = 4C-View Validation ID, address 1
Polling Loops | 1 = Basic_1
Filters | Display One-Key Poll
步驟 | 測試步驟 | 通過標準 | P/F
1 | RAM clear EGM（如有必要）。設定 EGM 為 Secure Enhanced Validation。啟用 handpay validation、receipt printing、printing restricted tickets、validation extension（若支援）。
2 | 啟動 Polling Loop。發送 F1。 | EGM 回應 F1： | (01) EGM address（無 wakeup bit） | (A0) 1-byte command | (0000) 2-BCD game number = 0 | 1-byte Features1 | 1-byte Features2 | 1-byte Features3 | 3-byte reserved, LSB first | 2-byte CRC, LSB first | | Features1 bit 5 = 0 且 bit 6 = 1（Enhanced validation） | Features1 bit 4 = 1（若支援 validation extension），否則 = 0 | Features1 bit 7 = 1（若 ticket redemption enabled），否則 = 0 | Features2 bit 0 = 1（若 ticket amount 含在 total cancelled credits 中），否則 = 0
3 | 觀察 trace window 30 秒。 | EGM 每 15 秒發送 exception 3F 。 | EGM 不可遊玩且處於 validation tilt 狀態。
4 | 停止 Loop 1。開主門。Power cycle EGM 並等待完全重啟。
5 | 清除 trace window。啟動 Loop 1 並觀察 trace window。 | EGM 重啟後第一個回報的 exception 為 3F 。其他 exception 在 3F 之後才回報。 | EGM 持續每 15 秒回報 exception 3F 。 | EGM 仍不可遊玩且處於 validation tilt 狀態。
6 | 發送 F2。 | EGM 回應 F2： | EGM address（無 wakeup bit） | (4C) 1-byte command | (010010) 3-byte machine validation ID, LSB first | (010000) 3-byte sequence number, LSB first | (0000-FFFF) 2-byte CRC, LSB first | | EGM 不再發送 exception 3F 。 | EGM 變為可遊玩或 validation tilt 解除。
7 | 發送 F4。 | EGM 回應 F4 與步驟 6 完全相同。 | EGM 保持可遊玩且無 validation tilt。
8 | 發送 F3。 | EGM 回應 F3 格式同步驟 6，但 sequence number = 0x99 。
9 | 發送 F4。 | EGM 回應 F4 與步驟 8 完全相同。
10 | Ctrl + F2。 | EGM NACK 或忽略 F2。
11 | 發送 F4。 | EGM 回應 F4 與步驟 9 完全相同。
12 | Ctrl + F4。 | EGM NACK 或忽略 F4。
13 | Power cycle EGM 並等待 EGM 與 host 重新建立通訊。 | EGM 斷電後不發送 exception 3F 。
備註： EGM 只能設定為一種 ticket validation 類型。
