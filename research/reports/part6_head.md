### 12.1 `[Long Poll Commands]` — the full command surface

All 122 entries from `C:\IGT3\sastest.ini` lines 315–658, in file order.
118 distinct function codes; `$6F`, `$71`, `$73` and `$AF` each appear twice (two different

Flag columns follow the INI header comment order:
**LEN** = length byte, **TRN** = transaction number, **ACK** = ACK byte,
**TYP** = type byte, **STS** = status/crypt byte, **CRC** = append CRC16,
**#Box** = declared number of input boxes.
